## Rules that affect how we build
- **AI is allowed for the final project, but the essence of the work must be mine**, and AI use must be cited in code comments. That is why `CLAUDE.md` keeps `src/lib/*` for me to write and requires an `AI-assisted` comment on files Claude writes.
- **Collaboration** is allowed only with one or two CS50 classmates who contribute equally. Valeria is not taking CS50, so the CS50 submission is mine alone: README says what she did (research, data, design) and that the code is mine.
- Any language and infrastructure are allowed, as long as the project draws on the course (here: SQL, JavaScript, HTML/CSS concepts, data structures).

## Deliverables
- [ ] `README.md`: title, video URL, description of several hundred words (about 750 typical): what it is, what each file does, design choices and why. Written by me.
- [ ] Video, max 3 minutes. Opens with: project title, my name, GitHub and edX usernames, city and country, recording date. Then the demo. YouTube, unlisted is fine.
- [ ] Submit the video through the CS50 form.
- [ ] From the project folder: `submit50 cs50/problems/2026/x/project`
- [ ] Check cs50.me/cs50x and claim the certificate.
- Deadline: Dec 31, 2026, 23:59 UTC.

## Submitting from this codespace (no need for the CS50 codespace)
The CS50 page allows infrastructure other than the CS50 Codespace. To keep `node_modules` out of the submission:
```bash
pip install submit50
git clone <this repo URL> /tmp/uni-cs50
cd /tmp/uni-cs50
submit50 cs50/problems/2026/x/project
```
The clone has no `node_modules` or `.env`, because they are in `.gitignore`.
