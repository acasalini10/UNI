# App Store release checklist

## Accounts
- [x] Apple Developer Program, individual, enrolled Oct 15, 2026 (valid one year; check auto-renewal before Oct 2027)
- [ ] Identity check approved
- [ ] Expo account; `eas login` in the codespace
- [ ] App Store Connect: create the app record (name, bundle ID `com.uni.app` or similar)

## Required by App Review
- [ ] Privacy policy URL (a public page is enough)
- [ ] Support URL or email
- [ ] In-app account deletion (required when the app has sign-up)
- [ ] Demo account for the reviewer (email and password) in the review notes, with a profile already filled in
- [ ] No placeholder or sample content; every program links to its official page
- [ ] No buttons or links to buy anything outside the app
- [ ] No university logos, crests or ranking brand marks in the app, icon, screenshots or keywords (guideline 5.2)
- [ ] App Privacy questionnaire: email, name, academic profile, citizenship, budget range, uploaded documents; not used for tracking
- [ ] AI feedback: say in the app and in the review notes that it is generated by AI
- [ ] AI consent (guideline 5.1.2(i)): explicit permission before CV and statement go to Claude (screen 6a), switch in Settings, Anthropic named in the privacy policy
- [ ] Sign in with Apple and Google both working (Apple is required when Google sign-in is offered)
- [ ] Every button and row works; nothing "coming soon" or locked (guideline 2.1)
- [ ] Language switch offers English and Spanish
- [ ] Deadline reminders ask for notification permission only when the student turns them on
- [ ] Optional profile questions (budget, who pays) say why we ask (guideline 5.1.1)
- [ ] iPhone only (`supportsTablet: false`); open once on an iPad to check the app does not crash in compatibility mode
- [ ] Age rating questionnaire

## Store listing
- [ ] Check that the name "UNI" is free on the App Store; pick the final name before making icon and screenshots
- [ ] App name, subtitle, description, keywords (Spanish and English)
- [ ] Icon 1024×1024, no transparency
- [ ] Screenshots for 6.9" iPhone (at least 3)

## Build and submit
- [ ] `eas build -p ios --profile production`
- [ ] Install from TestFlight and run the full flow on a real iPhone
- [ ] `eas submit -p ios`, then submit for review in App Store Connect
- [ ] Release: manual, so it goes live when we choose

## Fallback if review is not done by Nov 10
TestFlight public link: classmates install the TestFlight app and join with the link. Send the build to external testing on Oct 29, before the App Store submission, so the beta review is done early. Last resort: Expo web version at a public link.
