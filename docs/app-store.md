# App Store release checklist

## Accounts
- [x] Apple Developer Program, individual, enrolled Oct 15, 2026 (valid one year; check auto-renewal before Oct 2027)
- [x] Identity check approved
- [ ] Expo account; `eas login` in the codespace
- [ ] App Store Connect: create the app record (name, bundle ID `com.acasalini.uni`, App ID already registered Nov 3)

## Required by App Review
- [ ] Privacy policy URL (a public page is enough)
- [ ] Support URL or email
- [ ] In-app account deletion (required when the app has sign-up)
- [ ] Demo account for the reviewer (email and password) in the review notes, with a profile already filled in
- [ ] No placeholder or sample content; every program links to its official page
- [ ] No buttons or links to buy anything outside the app
- [ ] No university logos, crests or ranking brand marks in the app, icon, screenshots or keywords (guideline 5.2)
- [ ] App Privacy questionnaire: email, name, academic profile, citizenship, budget range, uploaded documents; not used for tracking
- [ ] AI feedback: say in the app and in the review notes that it is generated by AI
- [ ] AI consent (guideline 5.1.2(i)): explicit permission before CV and statement go to Claude (screen 6a), switch in Settings, Anthropic named in the privacy policy
- [ ] Sign in with Apple and Google both working (Apple is required when Google sign-in is offered)
- [ ] Every button and row works; nothing "coming soon" or locked (guideline 2.1)
- [ ] Language switch offers English and Spanish
- [x] Deadline reminders ask for notification permission only when the student turns them on
- [ ] Optional profile questions (budget, who pays) say why we ask (guideline 5.1.1)
- [ ] iPhone only (`supportsTablet: false`); open once on an iPad to check the app does not crash in compatibility mode
- [ ] Age rating questionnaire

## Store listing
- [ ] Check that the name "UNI" is free on the App Store; pick the final name before making icon and screenshots
- [ ] App name, subtitle, description, keywords (Spanish and English)
- [x] Icon 1024×1024, no transparency: graduation cap on navy, in `assets/icon.png` (Nov 5)
- [ ] Screenshots for 6.9" iPhone (at least 3)

## Build and submit
- [x] `eas.json` with a `production` profile; build number managed by EAS (Nov 5)
- [ ] `eas build -p ios --profile production`
- [ ] Install from TestFlight and run the full flow on a real iPhone
- [ ] `eas submit -p ios`, then submit for review in App Store Connect
- [ ] Release: manual, so it goes live when we choose

## TestFlight external testing (draft, Nov 5)
Paste into App Store Connect → TestFlight. Test Information is per language: fill English and Spanish. Update "What to Test" for every build sent to testers.

Before sending a build to beta review:
- [ ] Privacy policy URL (Valeria): required in Test Information for external testing
- [ ] Feedback email (the dedicated Gmail or a support address)
- [ ] Demo account created in the Supabase project the build uses, with profile filled in; email and password added below in App Store Connect only, never in git
- [ ] Contact for the reviewer: first name, last name, phone, email
- [ ] Check the build against the risks below

Risks in the current build (Nov 5, built before PR #11):
- The four tabs show only a title. Beta review is lighter than App Review but can still reject an app with empty screens (guideline 2.1). Send the build that has at least profile setup (PR #11) and, if possible, Programs.
- Sign out is shown only in development (`__DEV__` in `app/(tabs)/profile.tsx`), so testers cannot sign out in the TestFlight build.
- No account deletion yet (guideline 5.1.1(v)). Usually not checked in beta review, but required for the App Store.

### Beta App Description (English)
UNI helps international students choose a master's program abroad and strengthen their application. This beta lets you create an account and set up your academic profile. Next builds add the program list with fit labels and official costs, application tracking, and AI feedback on your CV and statement.

### Beta App Description (Spanish)
UNI ayuda a estudiantes internacionales a elegir una maestría en el extranjero y a mejorar su solicitud. En esta beta puedes crear una cuenta y configurar tu perfil académico. Las próximas versiones agregan la lista de programas con etiqueta de compatibilidad y costos oficiales, el seguimiento de solicitudes y retroalimentación con IA sobre tu CV y tu carta de motivación.

### What to Test (English)
- Create an account with email and password, or with Sign in with Apple.
- Fill in your academic profile.
- If you already have an account: try a wrong password, then reset it with the 6-digit code sent by email.
- Tell us anything that looks wrong or confusing: use the screenshot feedback in TestFlight.

### What to Test (Spanish)
- Crea una cuenta con correo y contraseña, o con Sign in with Apple.
- Completa tu perfil académico.
- Si ya tienes una cuenta: prueba una contraseña incorrecta y luego restablécela con el código de 6 dígitos que llega por correo.
- Cuéntanos todo lo que se vea mal o sea confuso: usa la captura de pantalla con comentarios de TestFlight.

### Review Notes (English only)
UNI is a student project (Universidad Panamericana and Harvard CS50x) that helps international students choose master's programs abroad. Sign in with the demo account below, or create a new account with any email (no email confirmation is needed). Sign in with Apple is also available. This beta covers sign-in and profile setup; program data, application tracking and AI feedback are not in this build. The app has no purchases and no ads.
